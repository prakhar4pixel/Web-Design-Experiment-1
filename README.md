# Prakhar Singh — Developer Portfolio

A responsive, high-performance, and accessible developer portfolio designed to showcase software engineering projects, hackathon victories, industry certifications, and technical skills.

---

## 🌟 Key Features

- **Dynamic Interactive Hero Section**:
  - Live HTML5 Canvas particle network animation (`<canvas id="heroCanvas">`)
  - Fast status indicators, key achievement metrics (Projects, Hackathons Won, DSA problems solved)
  - Quick access social pills (GitHub, LinkedIn, LeetCode, Email)
- **Technical Skills Showcase**:
  - Categorized breakdown: **Frontend Engineering**, **Backend & Databases**, and **DevOps & Cloud Tools**
- **Featured Projects**:
  - Interactive category filter (**All**, **Full Stack**, **AI & Cloud**, **Web Apps**)
  - Key performance metrics, tech stack pills, and GitHub / Live demo links
  - **DevFlow**: Real-time collaborative cloud code workspace with WebRTC & Docker execution
  - **MediScan AI**: AI-driven clinical triage & symptom evaluation portal
  - **FinTrack Pro**: Automated personal finance & portfolio analytics
  - **EcoTransit**: Carbon-optimized urban multimodal transit engine
- **Hackathon Achievements**:
  - Dedicated showcase of competitive sprints with problem statements, roles, team sizes, and impact
  - **Smart India Hackathon (SIH) 2025** — Top 5 Grand Finalist (CivicPulse)
  - **HackVerse National Hackathon 2025** — 1st Runner Up & \$1,000 Award (CrediZKP)
  - **Devfolio HackCraft 2024** — Best Innovation Award (VocalDev)
- **Professional Certifications**:
  - AWS Certified Cloud Practitioner (`AWS-8942-CLF`)
  - Meta Front-End Developer Specialization (`META-FED-77192`)
  - Google Cloud Computing Foundations (`GCCF-9021-IN`)
  - HackerRank Problem Solving (Advanced) (`HR-PS-ADV-3104`)
  - Interactive "Verify Credential" modal simulation
- **Dark / Light Theme Switcher**:
  - Persistent theme selection saved via `localStorage`
- **Interactive Contact Form**:
  - Client-side validation for name, email regex, and message length
  - Success banner & toast notifications
  - One-click email copy to clipboard
- **Responsive & Accessible**:
  - Mobile slide-out drawer menu, fluid typography, smooth scrolling, and back-to-top button

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with a local static server:

```bash
# Using Python
python3 -m http.server 3000

# Using Node.js npx
npx serve .
```

Then visit `http://localhost:3000` in your browser.

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5 with accessibility ARIA standards
- **Styling**: Modern CSS3 (Custom Properties / Design Tokens, Flexbox, CSS Grid, Glassmorphism)
- **Interactivity**: Vanilla JavaScript (ES6+, Canvas API, Clipboard API, LocalStorage)
